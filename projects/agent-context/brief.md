# Agent Context

## Outcome

Give a human or new agent a trustworthy answer to "where is this project, where did we stop, and what next?"

## Scope And Rules

Keep portable context in this standalone folder. Do not relocate source repositories. Use one registry, one project folder per ID, concise current state, append-only history, and evidence-backed tasks. Private by default; no sensitive datasets or credentials.

## Sources

- Root AGENTS.md and README.md govern this hub.
- VS Code Local hooks: https://code.visualstudio.com/docs/agent-customization/hooks
- Stop payload/output: https://code.visualstudio.com/docs/agents/reference/hooks-reference

## Completion

Registry, examples, seeded handoffs, validation tool/tests, and an opt-in checkpoint integration. Sync provisioning and remote publication are separate user choices.
